# ActionLab

**面向基础模型的行动层基础设施。**

ActionLab 是一个专注于模型能力延申的开源组织。

我们希望让模型从“会说”走向“会做”，建设围绕基础模型的能力层与执行层，包括：

- **Skill**：可复用的能力模块
- **Tool Use**：与外部系统/API 的结构化交互
- **Memory**：短期记忆、长期记忆与工作流记忆
- **Agent Runtime**：执行、规划、编排与控制循环
- **Workflow**：可靠的任务拆解与自动化执行
- **Embodied Intelligence**：面向真实世界与物理系统的具身能力接口

## 我们的目标

构建基础模型的能力层与行动层基础设施，让模型真正具备可组合、可执行、可落地的真实生产力。

## 研究与工程方向

- Skill 架构与 Skill Hub
- Tool Calling 与执行协议
- Agent 基础设施与 Runtime
- Memory 与上下文管理
- 多 Agent 协同
- 具身智能与行动型 AI 系统
- 面向模型原生系统的开放工程标准

## 核心原则

- **重执行，不重演示**
- **重组合，不重大而全**
- **重开放，不重封闭**
- **重可靠，不重玄学**
- **工程优先**
